# منبع رزومه‌ی حسن نصیری خونساری — v1.5

دو نسخه از یک منبع ساخته می‌شوند: حرفه‌ای (resume-pro) و کامل (resume-full). هر کدام دوزبانه است: اول انگلیسی، بعد فارسی با محتوای کاملاً متناظر.

## فایل‌ها
- content_cv.py — همه‌ی متن‌ها، انگلیسی و فارسی کنار هم. برای ویرایش محتوا فقط همین فایل را تغییر دهید. کلید full=True یعنی آن مورد فقط در نسخه‌ی کامل می‌آید.
- build_cv.py — چیدمان، CSS (تم لینکدین: سرمه‌ای #0B1F3F و قرمز #C8203A) و ساخت HTML و PDF با WeasyPrint.
- img/ — عکس‌ها و کدهای QR. کد QR هر لینک جدید با کتابخانه‌ی qrcode ساخته و با نام qr-<کلید>.png اینجا گذاشته می‌شود.
- fonts/ — Vazirmatn (داخل HTML به صورت base64 جاسازی می‌شود).
- resume-pro.html و resume-full.html — HTML نهایی؛ کنار پوشه‌ی img باز شوند.

## ساخت
    pip install weasyprint qrcode
    python build_cv.py

## قواعد نگارشی که باید حفظ شوند
- هرگز همزه به‌جای «ی» میانجی (بنویس «رزومه‌ی»، نه «رزومهٔ»). اسکریپت اگر همزه، ي یا ك عربی ببیند، متوقف می‌شود.
- ارقام فارسی در بخش فارسی، متن‌ها تراز دوطرفه.
- «لایه‌نشانی مستقیم فلز»، نه «رسوب مستقیم فلز».
- ادعای «نخستین» فقط با قید «از این نوع در ایران».
- نام نهاد حامی دستگاه تست زانو عمومی نشود.
